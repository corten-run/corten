- The deploy guide says what the command given to `corten build --profile-from` must cover:
  every route whose cost matters, in every response coding its readers get. A route or coding
  the command leaves out can cost more than in a build with no profile, measured on card-market.
  ([deploying](https://github.com/corten-run/corten/blob/main/docs/guide/deploy.md#a-profile-guided-build))
