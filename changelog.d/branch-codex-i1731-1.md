- `corten build` passes Cargo's `--features` (`-F`), `--all-features`, `--no-default-features`, `--locked`, `--package` (`-p`) and `--bin`, given before `--profile-from`, to each build it runs, so an app whose release needs features, a package, a binary or the lock can be built with a profile. Any other argument is still refused, `--target`, `--target-dir` and `--profile` included.
