- Requests that miss a kept `Public` page together, the first after a start too, run its handler
  once: the others wait, within their deadline, and are given that page, or run their own when it
  is not kept; once the kept pages fill their bound, a new URL's handler runs at most twice, or
  more if other new URLs make the app forget the URLs it knows meanwhile.
  [Requests that miss a kept page together each run the handler](https://github.com/corten-run/corten/issues/1792)
