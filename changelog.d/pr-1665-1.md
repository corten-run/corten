- **Breaking:** The table kit's `SortHeader` now takes `links` and `on:connect`. Update a copied kit with `corten ui add --merge table`. For client sorting, pass the table's typed `SortLinks` refs to each header and register them with `on:connect={rows::connect(target, up, down, first)}`; `ordered::send` and `ordered::link` still take table IDs. For server sorting or a custom handler that manages its own addresses, pass `links={None}` and `on:connect={None::<Handler>}`.
