- For a client that accepts gzip but not zstd, a page, patch or JSON answer up to 16 KiB is now gzip made by libdeflate, and
  so is a larger one when the client accepts gzip alone; a larger one stays brotli where the client accepts it. `compress` now also
  compiles libdeflate's C sources ([#1971 Compress a request's small body with gzip by libdeflate for a client without zstd](https://github.com/corten-run/corten/pull/1971)).
