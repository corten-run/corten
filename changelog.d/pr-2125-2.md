- A nav link (`req.nav`, `req.nav_of`, an entry's `also`) whose URL is not a path on this site,
  such as `//host/x` from a route implemented by hand, is never current: the runtime no longer
  marks it after a client navigation where the server did not
  ([#2119 A nav entry cannot be current at an older address that serves the same page](https://github.com/corten-run/corten/issues/2119)).
