- `Accept-Language` and `Accept-Encoding` use the same HTTP qvalue grammar (0 to 1, up to three decimals). Items with malformed or repeated weights are skipped.
  Quoted parameters hide apparent weights and commas; after an unterminated quote, the parser skips that item and recovers later alternatives.
  ([#1585 Parse negotiation weights using the HTTP qvalue grammar](https://github.com/corten-run/corten/pull/1585))
