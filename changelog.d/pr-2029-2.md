- While a connection's kept deadline timer is set, the runtime's driver runs about 190
  instructions more each time it parks, whichever connection is served next: about 4% more CPU
  time a request, measured where it parks once a request, and nothing new for an app with a
  timer of its own. A connection allocates 128 bytes more
  ([cancellation](https://github.com/corten-run/corten/blob/main/docs/guide/cancellation.md#cancellation),
  [#2029 Keep one deadline timer for a connection's requests](https://github.com/corten-run/corten/pull/2029)).
