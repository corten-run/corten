- While a connection's kept deadline timer is set, each wait of a server thread for work costs
  about 190 instructions more, whichever connection it serves: about 4% more CPU time a request,
  measured where a thread waits once a request, and nothing new for an app with a timer of its
  own. Each connection holds 128 bytes more
