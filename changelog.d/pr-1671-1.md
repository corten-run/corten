- **Breaking:** Hand-written named schemas calling the old hidden `Generator::define` helper now use `Generator::define::<Self>(read, name, make)`, without a string identity argument. Schema names must be non-reserved ASCII TypeScript identifiers without a dollar sign, so they also work as JSON Schema references and OpenAPI component keys. The derives check names at compile time; invalid hand-written names are rejected before a document is emitted. Generate separate JSON Schema and TypeScript definitions for distinct Rust types whose paths print the same, including types from different versions of one dependency. Reject a JSDoc import during declaration generation if it names the wrong definition.
