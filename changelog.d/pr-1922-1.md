- **Breaking:** The app keeps a `Public` whole body (JSON, text, a file) of 1,024 bytes or more whatever its type, and in a build without the `compress` feature too, where it kept only one it compresses. A `Public` PNG, PDF or other file of that size from a route of files is held by the app for its lifetime, its handler no longer runs for every such request, and its `ETag` is made once. A request that names no coding pays for the asking and gains no tag by it. `App::kept_answers(0)` keeps none.
  ([#1877 The tag's hash is a third of a request for a file the app does not compress: about 2.5 instructions a byte, made again for every answer that is not kept](https://github.com/corten-run/corten/issues/1877))
