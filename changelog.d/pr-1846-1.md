- A kept `Public` page, JSON, text or file answer of up to 32 KiB is now sent in brotli 5,
  made off the request once that kept copy has given 8,192 compressed answers, plus three a byte,
  to clients that rank brotli first. The count spreads the encoding's CPU, which those answers do
  not repay; a copy made again counts anew. Best effort ([A kept page is compressed at the level a per-request answer is](https://github.com/corten-run/corten/issues/1793)).
