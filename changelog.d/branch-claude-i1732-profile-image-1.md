- The Dockerfile `corten new` writes builds the image's binary with a profile of the app at work when its build is given the app's script: `docker build --build-arg PROFILE_FROM=train.sh .`. Without the argument the build is unchanged. The starter's own app took 32% fewer cycles a request built this way ([deploying](https://github.com/corten-run/corten/blob/main/docs/guide/deploy.md#a-profile-in-the-image)).
