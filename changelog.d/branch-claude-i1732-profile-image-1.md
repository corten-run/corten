- The Dockerfile `corten new` writes builds the image's binary with a profile of the app at work when its build is given the app's script: `docker build --build-arg PROFILE_FROM=train.sh .` runs `corten build --locked --profile-from sh train.sh` in the build stage, where it otherwise runs `cargo build --release --locked`. Without the argument the build is unchanged. On the starter's own app the profiled image used 32% fewer cycles a request on its home page, and 22% fewer where each answer is compressed (the deploy guide, "A profile in the image"). An app written before this release gets it by copying the two `RUN` lines and the `ARG` from a new app's Dockerfile.
