- `corten check` requires a fresh `Cargo.lock`: run `cargo build` or `corten dev` and commit the
  lock. `corten new` writes it, and `corten ui add` updates it when adding `corten-ui`. Starter and example images also build locked, with one [#1584 card-market's image and its paired bench recipe still build without --locked](https://github.com/corten-run/corten/issues/1584) exception.
