- The deploy guide now lists passing the browser's `Accept-Encoding` and `If-None-Match` on to the app among what a proxy must do, with how to check it: a page `GET` is tagged only for a request that accepts a coding or names a tag, so behind a proxy that takes `Accept-Encoding` off a browser that holds no tag is never sent one and gets the whole page each time. The guide's nginx configuration gains two lines: with `proxy_cache`, nginx passed no `If-None-Match` on, so a page it did not store was never answered `304`.
