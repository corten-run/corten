- **Breaking:** Pass the URI between method and headers in `Policy::same_origin`. Absolute-form writes, WebSocket handshakes, kept-page invalidation, notice cookies and debug form redirects use the target authority. A browser write without `Sec-Fetch-Site` that was accepted because its `Origin` matched the public `Host` can now get 403 if a proxy puts its internal name in the target. Have the proxy forward the public authority in the target, or a path with the public `Host`. [#2128 Use the target authority consistently for absolute-form requests](https://github.com/corten-run/corten/pull/2128).
